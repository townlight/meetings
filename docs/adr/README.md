# Historical Meetings architecture decisions

The numbered decision records in this directory retain their original bytes,
filenames and package identities. They describe decisions for their original
release lines. They are historical evidence, not current installation or import
instructions.

The current package is `townlight-meetings` 1.0.5, with principal import
`townlight_meetings` and dependency `townlight-core` 1.3.0.dev2. Use the current
owning README and user manual for this candidate. Fresh installation uses the
new branded database identifiers and refuses existing unmarked city data; no
in-place legacy upgrade or deprecated import shim is provided. Current installed
acceptance and publication remain pending.
